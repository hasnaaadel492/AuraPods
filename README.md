## 🌟 مميزات المشروع (Features)
- **معمارية متقدمة (Next.js 15 App Router):** استغلال ميزات الـ Server & Client Components لأداء فائق وسرعة تحميل ممتازة.
- **إدارة الحالة العالمية (Zustand State Management):** مزامنة فورية وكاملة للكميات، الأسعار، والألوان المختارة بين الصفحة الرئيسية، سلة التسوق (Cart Drawer)، وصفحة إتمام الطلب (Checkout).
- **التصميم والهوية البصرية (Warm Studio Theme):** تصميم عصري بلمسات دافئة وفخمة، متوافق 100% مع الأجهزة المختلفة وتخطيط الاتجاه العربي (RTL).
- **الخط العربي الرسمي:** دعم كامل لخط **Cairo** الراقي لضمان تجربة قراءة استثنائية.
- **دورة شراء متكاملة (E-Commerce Flow):**
  - **Color & Price Switcher:** تغيير لون المنتج وتحديث السعر فوراَ.
  - **Interactive Cart Drawer:** سلة تسوق جانبية مع أزرار التحكم بالكمية وحساب الإجمالي التلقائي.
  - **Checkout & Success Flow:** صفحة إتمام طلب متكاملة مع إدخال بيانات الشحن، اختيار طريقة الدفع، وشاشة تأكيد نجاح الطلب.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **State Management:** Zustand
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Typography:** Google Fonts (Cairo)
